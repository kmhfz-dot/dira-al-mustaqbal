INSTALLATION
1. Extract this ZIP.
2. Open the extracted folder.
3. Copy everything inside it into your local dira-al-mustaqbal repository folder.
4. Choose Merge folders and Replace files when Windows asks.
5. Open GitHub Desktop, review the changed files, then Commit and Push.
6. Wait around 1–3 minutes and refresh the website with Ctrl + F5.
