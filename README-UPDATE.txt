INSTALLATION
1. Open this patch folder.
2. Select everything inside it.
3. Copy into the local GitHub repository folder named dira-al-mustaqbal.
4. Choose Merge folders and Replace files when Windows asks.
5. Open index.html and products.html to test.
6. In GitHub Desktop, commit the changed files to main.
7. Click Push origin.
8. Refresh the live website with Ctrl + F5 after GitHub Pages finishes publishing.

IMPORTANT IMAGE NOTE
Belleville model names and links are based on the official Belleville website. Exact manufacturer colours and specifications should be confirmed through the official link shown in the product window.
