HOW TO APPLY THIS PATCH

1. Extract this ZIP.
2. Open the extracted dira-proper-product-images-fix-patch folder.
3. Select everything inside it and copy.
4. In GitHub Desktop, open the dira-al-mustaqbal repository.
5. Click Repository > Show in Explorer.
6. Paste the copied files directly into the repository folder.
7. Choose Merge folders and Replace files in the destination.
8. Return to GitHub Desktop.
9. Commit with: Fix product images and restore firearm assets
10. Click Push origin.
11. Wait for GitHub Pages to deploy, then hard-refresh the website with Ctrl+F5.
