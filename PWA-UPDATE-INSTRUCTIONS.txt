DIRA AL MUSTAQBAL - ANDROID & APPLE APP UPDATE

1. Copy everything from this update folder into the main
   dira-al-mustaqbal repository folder.
2. Choose "Replace the files in the destination" when Windows asks.
3. In GitHub Desktop, use this summary:
   Add Android and Apple web app installation
4. Commit to main and push origin.
5. Wait 1-3 minutes for GitHub Pages to update.

WHAT THIS UPDATE ADDS
- Installable Android and desktop Progressive Web App.
- iPhone and iPad Add to Home Screen guidance.
- Dira branded Home Screen icons.
- Standalone app window without normal browser tabs.
- Service worker and offline fallback.
- Install App button across all five website pages.

AFTER PUBLISHING
- Android: visit the website in Chrome and tap Install App.
- iPhone: visit in Safari, tap Install App, then follow the displayed steps.
