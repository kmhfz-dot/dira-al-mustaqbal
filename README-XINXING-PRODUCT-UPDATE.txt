INSTALL
1. Extract this ZIP.
2. Open the extracted folder.

4. Choose Merge folders and Replace files when prompted.
5. Commit and push with GitHub Desktop.
6. Refresh the website with Ctrl + F5 after GitHub Pages finishes publishing.
